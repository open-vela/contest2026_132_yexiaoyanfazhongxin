## 📋 项目简介

体态安全卫士是一款运行在智能手表上的体态监测应用，通过端侧 AI 实时识别用户体态异常（久坐、低头、跷二郎腿等），并提供完整的隐私安全保护体系。

### 核心特性

- 🤖 **端侧 AI 推理**：无需联网，本地完成体态识别
- 🛡️ **隐私优先架构**：差分隐私脱敏 + 分级加密 + 自动销毁
- 🔋 **超低功耗**：自适应采样 + Duty-cycling，8小时功耗<15%
- ⌚ **双表盘适配**：圆形/方形表盘自适应布局

## 🚀 快速开始

### 环境要求

- OpenVela SDK
- 模拟器或真实设备

### 运行步骤

```bash
# 1. 进入项目目录
cd quickapp/posture-guard

# 2. 安装依赖（如有）
npm install

# 3. 编译项目
openvela build

# 4. 启动模拟器运行
openvela run
```

### 演示模式

1. 启动应用后进入设置页
2. 开启"Mock模式"
3. 选择演示场景（办公/久坐/跷腿/混合）
4. 返回首页查看实时识别效果

## 🔬 核心算法

### 特征提取

从250帧滑动窗口（5秒@50Hz）提取8维特征：

| 特征 | 说明 | 计算方法 |
|------|------|----------|
| accMean | 加速度均值 | 窗口内X/Y/Z轴平均值 |
| accVar | 加速度方差 | 窗口内方差，反映运动强度 |
| gyroPitch | 俯仰角 | 互补滤波融合加速度计和陀螺仪 |
| gyroRoll | 横滚角 | 互补滤波 |
| dominantFreq | 主频 | 64点DFT频谱分析 |
| zeroCrossRate | 过零率 | 信号过零次数/总点数 |
| asymmetryIndex | 不对称指数 | 左右运动幅度差异 |
| orientation | 姿态四元数 | 互补滤波输出 |

### 动态阈值分类

```javascript
// 分类优先级：久坐 > 低头 > 跷腿 > 走路 > 正常
if (features.accVar < sedentaryThreshold && duration > 1800s) {
  return SEDENTARY;
}
if (features.gyroPitch < forwardTiltThreshold && duration > 10s) {
  return FORWARD_TILT;
}
// ...
```

### 差分隐私

采用 Laplace 机制为数值数据添加噪声：

```javascript
// ε = 0.1, sensitivity = 1.0
const scale = sensitivity / epsilon; // b = 10
const noise = -scale * sign(u) * ln(1 - 2|u|); // u ~ U(-0.5, 0.5)
const noisyValue = originalValue + noise;
```

## 🔐 安全设计

### 分级加密体系

| 级别 | 数据类型 | 加密算法 | 存储位置 | 生命周期 |
|------|----------|----------|----------|----------|
| L1 | 统计数据 | AES-128-GCM | 普通区域 | 7-90天 |
| L2 | 生理趋势 | AES-256-GCM | 隔离区域 | 1-30天 |
| L3 | 原始特征 | AES-256-GCM | Shamir分片 | 24小时强制销毁 |

### Shamir 密钥分片 (2-of-3)

```
主密钥 → 多项式 f(x) = secret + a*x (mod p)
分片1: f(1) → 内存临时持有
分片2: f(2) → 加密写入文件头
分片3: f(3) → 独立小文件存储

恢复: 任意2个分片 → 拉格朗日插值 → secret
```

### 数据生命周期状态机

```
创建 → 热数据(24h) → 温数据(7天) → 冷数据(30天) → 销毁
                           ↓
                    L3: 24h强制销毁
```
